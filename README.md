# STEP to Point Cloud

## Installation

-create a virutal environment
-activte the virtual environment
-install teh dependencies from requirements.txt

## Use

-put a step assembly file in the input folder
-name the step file "baugruppe.step"
-run the main script: "python main.py"
-in the output folder a PLY, PCD and XYZ file with the clustered pointcloud are generated
